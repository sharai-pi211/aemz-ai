# Рекомендательная система подбора косметики

Система работает с датасетом `socrimea_cosmetics_dataset.csv` и подбирает товары по параметрам пользователя.

## Что анализируется

Пользователь может указать:

- категорию: `лицо`, `волосы`, `тело`;
- тип продукта: `крем`, `шампунь`, `тоник`, `гель для душа`, `бальзам`, `маска` и т.д.;
- зону применения: `лицо`, `кожа головы`, `тело`, `руки`, `ноги`, `губы`;
- тип кожи: `сухая`, `жирная`, `чувствительная`, `проблемная`, `комбинированная`;
- тип волос: `сухие`, `жирные`, `тонкие`, `поврежденные`;
- проблемы: `акне`, `сухость`, `шелушение`, `зуд`, `перхоть`, `выпадение волос`, `дерматит`, `псориаз`;
- желаемые эффекты: `увлажнение`, `питание`, `очищение`, `восстановление`, `снятие раздражения`;
- аллергии и компоненты, которые нужно исключить.

## Как работает алгоритм

1. Загружается датасет косметики.
2. Пользовательский запрос нормализуется.
3. Система исключает товары, если:
   - не совпадает строгая категория;
   - в составе есть компонент из списка аллергий;
   - в составе есть нежелательный компонент.
4. Оставшимся товарам начисляются баллы:
   - совпадение категории;
   - совпадение типа продукта;
   - совпадение зоны применения;
   - совпадение типа кожи или волос;
   - совпадение проблем;
   - совпадение желаемых эффектов.
5. Дополнительно применяется TF-IDF похожесть между запросом пользователя и текстовыми признаками товара.
6. Товары сортируются по итоговому баллу и выводятся с объяснением.

## Запуск в консоли

```bash
pip install -r requirements.txt
python cosmetics_recommender.py
```

Пример запуска со своим запросом:

```bash
python cosmetics_recommender.py --request "{\"category\":\"лицо\",\"product_type\":\"крем\",\"target_area\":\"лицо\",\"skin_type\":\"сухая\",\"concerns\":[\"сухость\",\"шелушение\"],\"desired_effects\":[\"увлажнение\",\"питание\"],\"allergies\":[\"прополис\"],\"avoid_ingredients\":[\"отдушки\"]}"
```

## Запуск интерфейса

streamlit run streamlit_app.py

## Как описать в работе

В работе можно написать:

> В рамках практической части разработана гибридная рекомендательная система подбора косметических средств. Система использует структурированный датасет товаров и анализирует входные параметры пользователя: категорию ухода, тип продукта, зону применения, тип кожи или волос, имеющиеся проблемы, желаемый эффект, аллергии и индивидуальные ограничения. На первом этапе выполняется фильтрация неподходящих товаров, на втором — расчет коэффициента соответствия товара запросу пользователя. Для повышения качества подбора дополнительно используется текстовое сходство между пользовательским запросом и признаками товара на основе TF-IDF. Результатом работы системы является ранжированный список косметических средств с пояснением причин рекомендации.
